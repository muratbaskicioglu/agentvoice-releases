# AgentVoice — Releases

Public download host for **AgentVoice** (macOS dictation app).

This repository contains **only signed & notarized release binaries** — no source code.
The application source is maintained privately.

## Download

**[⤓ Download latest for macOS (Apple Silicon)](https://github.com/muratbaskicioglu/agentvoice-releases/releases/latest/download/AgentVoice-arm64.dmg)**

- `AgentVoice-arm64.dmg` — Apple Silicon (arm64)
- Signed with Developer ID Application + hardened runtime, notarized by Apple, ticket stapled.

The download link above always resolves to the newest published release.

## Install

1. Double-click the downloaded `AgentVoice-arm64.dmg`.
2. Drag **AgentVoice** into your Applications folder.
3. On first launch, grant the microphone permission when prompted.
